# 文档解析

解析器把原始文件字节解析成结构化内容（文本块、表格块、图片块），分块器只面向解析后的结构化文本工作，不关心原始文件格式。

## 1. 两个解析器

| 解析器 | 适用场景 | 输出 |
|--------|---------|------|
| TikaDocumentParser | txt / md / html / csv / doc / docx / xls / xlsx 等简单文本 | 文本块 |
| MineruDocumentParser | 表格 + 图片 + 文本混排的复杂 PDF / 扫描件 | 文本块 / 表格块 / 图片块 |

框架不根据文件格式自动判断用哪个，由调用方按场景选择。

## 2. 读取原始文档

```java
RawDocument rawDocument = new LocalDocumentReader(Path.of("xxx.pdf")).read();
// rawDocument.fileName() / rawDocument.content() / rawDocument.metadata()
```

`LocalDocumentReader` 参数：`Path` 文件路径。

## 3. Tika 简单文本解析

```java
DocumentParser parser = new TikaDocumentParser();
List<Document> documents = parser.parseToDocuments(rawDocument);
```

无需额外配置。

## 4. MinerU 多模态解析

```java
MineruDocumentParser parser = MineruDocumentParser.builder()
        .authToken(mineruToken)                    // MinerU 在线服务 token
        .enableImageUnderstanding(true)            // 是否用 VLM 生成图片语义描述
        .imageChatModel(vlmChatModel)              // 开启图片理解时必传
        .imageWorkers(4)                           // 图片理解并发数
        .assetStore(assetStore)                    // 图片资产存储（可选）
        .build();

List<Document> documents = parser.parseToDocuments(rawDocument);
```

关键参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| authToken | String | 是 | MinerU 在线服务 token |
| enableImageUnderstanding | boolean | 否 | 是否用 VLM 生成图片语义描述写回 Markdown |
| imageChatModel | ChatModel | 开启图片理解时 | 多模态模型 |
| imageWorkers | int | 否 | 图片理解并发数，默认 4 |
| assetStore | DocumentAssetStore | 否 | 图片资产存储，不传则图片引用不落地为可访问 URL |

MinerU 是异步任务，解析耗时较长（分钟级）。当前调用在线服务（每天有大量免费额度），后续可私有化部署。

## 5. 图片资产存储

图片块需要落到可访问的存储，URI 写回 Markdown 引用。框架提供 SPI 与两个实现：

```java
// 本地磁盘（开发测试）
new LocalDocumentAssetStore(Path.of(".rag-assets"));
// 参数：Path 资产目录

// MinIO（生产，返回 http 可访问地址）
new MinioDocumentAssetStore(minioClient, "bucket", "http://192.168.113.52:19000");
// 参数：MinioClient 客户端、bucket 名、公开访问 baseUrl
```

调用方可基于 `DocumentAssetStore` 接口自建 S3 等实现。

## 6. 框架接管 vs 调用方传递

| 职责 | 谁负责 |
|------|--------|
| 字节解析、图片/表格识别、VLM 图片描述 | 框架 |
| 选择解析器、传 token / 模型 / 资产存储 | 调用方 |
| 资产落地、URI 写回 | 框架 |
| 资产存储位置（本地/MinIO/S3） | 调用方传递 |
