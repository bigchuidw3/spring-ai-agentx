# 文档分块

分块器把解析后的文本切成若干块，公共的 metadata 透传、chunkId 生成、图片/表格保护由框架统一处理，调用方只需选择切块器与参数。

## 1. 三种切块器

| 切块器 | 切分依据 | 适用场景 |
|--------|---------|---------|
| SlidingWindowSplitter | 固定窗口长度 | 文档结构不清晰、通用文本 |
| RecursiveSplitter | 有序分隔符 | QA 文档、有明确段落/分隔符 |
| HeadingSplitter | 标题层级 | 结构化文档（手册/说明书/制度） |

## 2. 按长度切分（SlidingWindowSplitter）

```java
List<Document> chunks = SlidingWindowSplitter.builder()
        .chunkSize(512)     // 每块最多 code point 数
        .overlap(64)        // 相邻块重叠
        .build()
        .split(documents);
```

## 3. 按符号切分（RecursiveSplitter）

```java
List<Document> chunks = RecursiveSplitter.builder()
        .chunkSize(512)
        .overlap(64)
        .separators("\n\n", "\n", "。", ";")   // 自定义分隔符，从粗到细
        .build()
        .split(documents);
```

不传 separators 时用默认中英文分隔符预设。

## 4. 按标题切分（HeadingSplitter，父子分块）

```java
List<Document> chunks = HeadingSplitter.builder()
        .maxHeadingLevel(2)          // 标题层级
        .chunkSize(512)
        .overlap(64)
        .maxParentSize(8000)         // 父块最大 code point 数（默认 8000），超限拆成子父块（0=不限）
        .enableParentChild(true)     // 开启父子分块
        .build()
        .split(documents);
```

父子分块结构：

- 父块：完整小节（标题 + 正文），`chunkRole=parent`、`skipEmbedding=1`，不参与向量召回
- 子块：小节内部切出的片段，`parentChunkId` 指向父块

父块默认上限为 `DEFAULT_MAX_PARENT_SIZE`（8000 code point，与 ReactAgent 工具结果源头卸载阈值 `toolResultEvictionChars` 默认 20000 字符保持安全比例）；传 `maxParentSize(0)` 可恢复不限制。超过上限的小节会先切成多个子父块（每个 ≤ maxParentSize），再对每个子父块切子块，子块 `parentChunkId` 指向所属子父块，避免超长父块撑爆上下文窗口。开启父子分块后，检索时命中子块可回查对应父块（配合父子检索器）。

## 5. 切块器公共参数

三种切块器均支持以下参数：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| chunkSize | int | 512 | 每块最大 code point 数 |
| overlap | int | 64 | 相邻块重叠长度 |
| preserveImageRef | boolean | true | 是否保护图片引用不被截断 |
| preserveTableRef | boolean | true | 是否保护 HTML 表格不被截断 |
| chunkIdGenerator | ChunkIdGenerator | UUID | chunkId 生成器 |

`HeadingSplitter` 额外参数：

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| maxHeadingLevel | int | 2 | 参与切分的标题最大层级（1-6） |
| maxParentSize | int | 8000 | 父块最大 code point 数，超限拆成多个子父块；0 表示不限制 |
| enableParentChild | boolean | false | 是否输出父块 |
| stripHeadings | boolean | false | 是否从正文剥离标题行 |
| separators | List\<String\> | 默认分隔符 | 小节内部子切分的分隔符 |

> **大小参数均可灵活传参**：`chunkSize` / `overlap` / `maxParentSize` / `maxHeadingLevel` 都通过各切块器的 builder 方法暴露，调用方按文档类型自由调。`maxParentSize` 建议 ≤ Agent 工具结果卸载阈值（ReactAgent `toolResultEvictionChars`，默认 20000 字符），否则父块召回后被 Agent 截断、丢失中间内容。

> **图片/表格长度计入 chunkSize**：开启 `preserveImageRef` / `preserveTableRef` 后，图片描述与 HTML 表格按真实长度计入 chunkSize（不再折叠成单个占位符），且作为原子单元不可拆分；贪心切分时每个 chunk 最多允许一个超限的原子单元。这样少文字 + 多截图的文档也能正常分块，避免超长块触发 Agent 工具结果截断。

## 6. documentId 与 chunkId

框架提供 `DocumentIdGenerator`：

```java
DocumentIdGenerator.getDocId();              // 随机 UUID
DocumentIdGenerator.getDocId(bytes);         // 基于内容 SHA-256，同一内容恒同 id
```

- `documentId`：文档唯一标识，入库时由调用方传入（建议用内容 hash，实现幂等重跑）
- `chunkId`：每个分块的唯一标识，框架自动生成

## 7. 框架接管 vs 调用方传递

| 职责 | 谁负责 |
|------|--------|
| chunkId 生成、metadata 透传、图片/表格保护 | 框架 |
| 选择切块器、chunkSize / overlap / 分隔符 / 标题层级 | 调用方 |
