# 动态会话参数

通过 `RunnableParams` 传递会话级别的参数，控制会话标识、用户标识和运行时参数注入。`RunnableParams` 在每次 Agent 调用时传入，影响会话记忆加载、任务管理和工具行为。

## 参数字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `conversationId` | `String` | 会话标识，用于 ChatMemory 会话记忆和 TaskManager 任务管理 |
| `userId` | `String` | 用户标识，用于长期记忆（用户画像）和语义记忆的维度 |
| `customParams` | `Map<String, Object>` | 提示词参数，通过 `addParam` 注入 system prompt，LLM 可见 |
| `toolParams` | `Map<String, Object>` | 工具参数，通过 `addToolParam` 保存，LLM 不可见，工具执行前由框架注入 |

## 基本用法

### 会话和用户标识

```java
RunnableParams params = RunnableParams.builder()
        .conversationId("conv_001")       // 会话标识
        .userId("user_123")               // 用户标识
        .build();

agent.call("帮我分析这段代码", params);
```

- `conversationId`：相同 ID 的多次调用共享会话记忆（短期记忆），框架自动加载历史对话
- `userId`：相同 ID 跨会话共享长期记忆（用户画像、语义记忆）

### 提示词参数注入

通过 `addParam` 注入参数到系统提示词，LLM 可以看到这些参数值：

```java
RunnableParams params = RunnableParams.builder()
        .addParam("language", "zh-CN")       // 注入: language: zh-CN
        .addParam("format", "markdown")      // 注入: format: markdown
        .build();

agent.call("写一段自我介绍", params);
```

系统提示词中会追加：

```
language: zh-CN
format: markdown
```

LLM 会根据这些参数调整输出。

## addParam 和 addToolParam 的区别

`addParam` 和 `addToolParam` 不再混在一起理解，它们分别解决两个问题：

| 方法 | 给谁用 | 是否进入提示词 | 适合场景 |
|------|--------|----------------|----------|
| `addParam` | 给 LLM 看 | 是 | 语言、输出格式、业务背景等可以公开的上下文 |
| `addToolParam` | 给工具执行用 | 否 | `userId`、`tenantId`、token 等不应依赖 LLM 生成的运行时参数 |

`addToolParam` 的工作原理是：工具执行前，框架读取当前工具的 `inputSchema`，只要工具声明了同名参数，就把 `toolParams` 中的真实值注入进去。

```java
RunnableParams params = RunnableParams.builder()
        .conversationId("conv_001")
        .addParam("language", "zh-CN")          // LLM 可见
        .addToolParam("userId", "user_123")     // LLM 不可见，工具执行前注入
        .build();

agent.call("查询我的订单", params);
```

如果某个工具声明了 `userId` 参数，框架会在调用这个工具前自动补上 `user_123`。即使 LLM 漏传、乱填，最终也会被框架覆盖。

## 完整示例

```java
RunnableParams params = RunnableParams.builder()
        .conversationId("conv_001")               // 会话记忆维度
        .userId("user_123")                       // 长期记忆维度
        .addParam("language", "zh-CN")            // LLM 可见的偏好参数
        .addParam("output_format", "json")        // LLM 可见的格式参数
        .addToolParam("userId", "user_123")       // 工具执行前注入
        .addToolParam("tenantId", "tenant_001")   // 工具执行前注入
        .build();

agent.call("查询用户列表", params);
```

## 内部实现

- `customParams` 中的参数在构建系统提示词时追加到末尾，LLM 可以感知
- `toolParams` 中的参数不进入提示词，只在工具执行前按 `inputSchema` 白名单注入
- 配合 `ToolContext`，工具也可以从上下文中获取 `userId`、`conversationId` 和完整 `RunnableParams`
